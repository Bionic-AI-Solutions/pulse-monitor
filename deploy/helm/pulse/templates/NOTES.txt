   External IP: Check with 'kubectl get svc {{ include "pulse.fullname" . }} -n {{ .Release.Namespace }}'
   Access Pulse at: http://<EXTERNAL-IP>:{{ .Values.service.port }}
{{- else if eq .Values.service.type "NodePort" }}

   Access Pulse at: http://<NODE-IP>:<NODE-PORT>
{{- else if .Values.ingress.enabled }}
   Ingress: {{ range .Values.ingress.hosts }}{{ .host }}{{ end }}
{{- else }}
   Internal: http://{{ include "pulse.fullname" . }}:{{ .Values.service.port }}
   Use port-forward: kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "pulse.fullname" . }} 7655:7655
{{- end }}

2. Create an API token from the Pulse UI under Settings → Security for the Docker agent.
3. Deploy the optional agent by enabling `agent.enabled` and providing your server URL and token.
